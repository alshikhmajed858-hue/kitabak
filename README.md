# كتابك — نسخة الإنتاج

هذه النسخة تجمع الموقع مع Worker + D1 + R2.

## ما أصبح جاهزًا
- تسجيل/دخول فعلي عبر الخادم.
- جلسات HttpOnly.
- تخزين المستخدمين والكتب والطلبات في D1.
- رفع إثبات الدفع إلى R2.
- لوحة إدارة بمفتاح سري.
- قبول/رفض الطلبات.
- رفع ملفات EPUB/PDF من لوحة الإدارة.
- منع تنزيل الكتاب قبل اعتماد الطلب.
- QR شام كاش الحقيقي الموجود في `shamcash-qr.jpg`.
- المعرّف: `d8dfa32ea57bd2c0c4f2babc8f97688c`.

## النشر
1. أنشئ Cloudflare Worker.
2. أنشئ D1 باسم `kitabak-db` ثم ضع database_id في wrangler.toml.
3. أنشئ R2 bucket باسم `kitabak-private`.
4. نفّذ `schema.sql` على D1.
5. نفّذ `wrangler secret put ADMIN_KEY` وضع مفتاحًا قويًا.
6. انشر باستخدام Wrangler.
7. افتح الموقع، ثم `/admin.html` وأدخل ADMIN_KEY.
8. ارفع الكتب التي تملك حق بيعها فقط.

## ملاحظات
- لا يوجد تحقق آلي من شام كاش في هذه النسخة؛ الطلب ينتظر مراجعة الإدارة.
- لا يمكن وضع مفتاح API سري لشام كاش من دون API رسمي ومصرح به.
- لا تضع ADMIN_KEY داخل ملفات الموقع.
- السعر الافتراضي في الأمثلة 2,000 ل.س ويمكن تغييره من لوحة الإدارة.
